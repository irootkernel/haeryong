# TASK-005-02: Implement anchored notes and conflict handling

## Outcome

Allow source-context notes with persistent anchors and explicit save/reattach semantics.

## Inputs

- [ui/screens.md](../../ui/screens.md)
- [contracts/http-api.md](../../contracts/http-api.md)
- [contracts/viewer-protocol.md](../../contracts/viewer-protocol.md)

## Implementation work

1. Bind notes to exact version/page_path and optional page-local region, with selected text/context fallback. A page needs no declared regions to support notes; a directory-level note is also possible.
2. Implement Save/Cancel, revision checks, unsaved drafts and explicit reattachment history.
3. Add independent Revisit flag and safe Markdown rendering.

## Required deliverables

- annotation repositories/API.
- Notes context editor.
- note conflict fixtures.
