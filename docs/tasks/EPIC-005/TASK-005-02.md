## Delivered result

Notes bind one exact immutable directory version, an optional resolved page with its
query and fragment, and an optional page-local region, with selected text and saved
context as fallback; a directory-level note is possible. The original anchor never
moves: a new version, a reused path or slug, or a repeated region label never transfers
a note, a missing or ambiguous anchor stays unresolved, and only an explicit
same-document reattachment changes the current anchor while history keeps every
revision. Save alone dispatches; drafts are separate from pending requests, a 412 keeps
the local draft beside the newer server revision (including large referenced bodies)
for an explicit reload or merge, and a merge after a concurrent reattach adopts the
server anchor without re-sending a stale context. Saved bodies and contexts stay owned
by their revisions and stream exactly under current owner authority after renderer or
session loss. Markdown renders as inert React text. Revisit is an independent document
flag with its own Home list; Review, Home continuation and Versions defaults are
unchanged.

Note CRUD, history, body and context streaming, Revisit and their filter, summary field
and capability flags are additive provisional contracts at schema revision 11; note and
Revisit writes keep the shared receipt-first precondition rules and return 409
INVALID_TRANSITION with details.lifecycle on trash or purged documents. The browser,
native and desktop clients share these operations, and the CLI adds `revisit show` and
`revisit set`.
