# TASK-005-01: Implement explicit version-specific review

## Outcome

Record user-initiated review transitions and Updated since review without conflating freshness or reading telemetry.

## Inputs

- [data-model.md](../../data-model.md)
- [ui/screens.md](../../ui/screens.md)
- [contracts/http-api.md](../../contracts/http-api.md)

## Implementation work

1. Implement Unreviewed/Reviewing/Reviewed transitions with owner scope and preconditions.
2. Store completion for the entire directory version and time, separate from page-level reading/location metadata. Visiting a page or every listed page never substitutes for explicit completion.
3. Show newer Unreviewed version while preserving old completion.

## Required deliverables

- review service/API/history.
- ReviewControl/Home summaries.
- personal state tests.
