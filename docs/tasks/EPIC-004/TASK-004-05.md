## Delivered result

Reader Copy link builds the exact document/version/page/page_query/page_fragment
and optional `#region` route, encoded once, under the approved base: the enabled
`network.external_base_url`, otherwise the client's trusted service origin (the
attached daemon in Wails), labelled local-only. It never carries credentials,
attachment IDs or reference-return state; a clipboard failure leaves selectable
text. A definitive credential loss on any screen moves to `/connect?return=` with
the validated route, and each verified return replaces that entry with a fresh
Reader context; native startup stays `checking` until the Go-held attachment
settles. Login returns accept only registered routes and query keys, one nonempty
`#region` on Reader routes and S05's exact `from_version`/`to_version`; anything
else returns home. Reload and Back/Forward keep the page, query, fragment and
region, and reference/backlink navigation stays bound to its activation.

The S05 Versions view lists the exact version history and fixes a comparison
pair in its URL: the Reader's version, or the target's predecessor, against the
latest version at entry. The pair survives publication, reload, Back/Forward and
transient disconnection, and every action checks the current authority when it
starts; a pair from another document is refused without showing its titles or
files. The two exact file inventories merge in UTF-8 byte order in bounded
batches, with visible unfinished scope, retry of the failed cursor and completion
only when both end. Metadata and page-region differences are asserted only when
both sides are verified or confirmed not supplied. Text previews read on request,
verify bytes and digest at the end and cancel on failure or pair change; downloads
belong to the exact version and path. Import new version mounts the shared import
control for this document with its captured base, Open latest is a separate fresh
lookup. Review was unavailable at this Task boundary; [TASK-005-01](../EPIC-005/TASK-005-01.md) supplies it now. Source observation,
the selected target's semantic coverage (keeping `attempt_run_id` on every page and
retry) and personal Review stay separate. No API operation, DTO, configuration
field or migration was added.
