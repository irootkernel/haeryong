# TASK-008-02: Implement bounded relationship/topic candidate discovery

## Outcome

Find potentially useful connections without all-pairs model calls or unsupported dependency claims.

## Inputs

## Implementation work

1. Use scoped search, source identities and region summaries to shortlist candidates.
2. Inspect actual candidate content before generating a supported related/theme proposal.
3. Retain rationale and distinguish source fact from thematic similarity.
4. Evaluate held-out labeled relationship/theme candidates, including tempting keyword-only false dependencies, useful cross-project links and absent themes. Record supported/unsupported/uncertain findings and actual candidate coverage.

## Required deliverables

- candidate retrieval pipeline.
- relationship evidence candidates.
- query/coverage tests.
