# TASK-008-05: Implement conflict-safe approval, rejection and undo

## Outcome

Apply findings under current policy and preserve explicit owner decisions across future scans.

## Inputs

- [contracts/http-api.md](../../contracts/http-api.md)
- [contracts/jobs-events.md](../../contracts/jobs-events.md)

## Implementation work

1. Recheck version, targets, lifecycle, scope and current policy before applying.
2. Record rejection evidence fingerprint and pinned categories; suppress identical dismissed proposals.
3. Implement revision-safe undo and stale-result reassessment flow. Reassessment uses POST /scans with finding_id, expected_finding_revision and explicitly captured authorized scope/depth; it starts a new assessment, never force-applies or silently approves/publishes the stale result.

- finding decision/undo service.
- rejection fingerprints.
- mid-flight conflict tests.
