# TASK-008-03: Implement region-scoped freshness assessment

## Outcome

Assess changed claims against exact current/pinned targets, preserving valid historical explanations.

## Inputs

- [contracts/source-access.md](../../contracts/source-access.md)
- [contracts/ai-adapter.md](../../contracts/ai-adapter.md)
- [ui/screens.md](../../ui/screens.md)
- [testing/knowledge-quality.md](../../testing/knowledge-quality.md)

## Implementation work

1. Identify potentially changed direct/indirect evidence including callers/configuration.
2. Compare claims under exact captured version/page_path and optional region plus source target scope, and classify supported results. Regionless results use page or version scope without an author region requirement. Pages lacking source evidence remain unknown/unverified; ordinary ingestion or reading never depends on this semantic assessment.
3. Store original provenance separately from later assessment and propagate only reassessment candidates through actual dependency evidence. Use the [schema registry](../../contracts/schema-registry.md) assessment and per-unit coverage records, including captured_at for the selected target separately from assessed_at. Persist the fixed required units and each outcome/reason; summary coverage is derived and units_url exposes the details. Apply the central citation-basis semantics without rewriting original evidence.
4. Evaluate direct/indirect changes, unrelated commits, historical intent and unavailable evidence on a labeled held-out set. Record false positives, missed changes, abstentions and scoped coverage separately.

## Required deliverables

- freshness evaluator and assessment records.
- evidence/uncertainty UI.
- indirect-impact fixtures.
