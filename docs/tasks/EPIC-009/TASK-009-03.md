# TASK-009-03: Enforce per-run budgets and uncertain-outcome accounting

## Outcome

Bound scheduled AI work using limits that the adapter actually supports and preserve ambiguity on retries.

## Inputs

- [contracts/jobs-events.md](../../contracts/jobs-events.md)
- [contracts/ai-adapter.md](../../contracts/ai-adapter.md)
- [operations/observability.md](../../operations/observability.md)

## Implementation work

1. Reserve/count external attempts under a transaction before dispatch.
2. Apply concurrency/deadline limits and report unknown provider usage honestly.
3. Pause expired/auth-limited work and reconcile uncertain attempts before retry decisions.
4. Count orphan/uncertain attempts independently of local worker slots; a changed attempt_generation fences application without pretending external resource use stopped.

## Required deliverables

- budget/attempt accounting.
- coordinator resource policies.
- quota/deadline fixtures.
