# TASK-006-01: Extend local jobs with provider attempts and reconciliation

## Outcome

Extend the existing local job/receipt/event foundation with externally executed provider attempts, cancellation/unknown-outcome accounting and stale-result fencing.

## Inputs

- [contracts/jobs-events.md](../../contracts/jobs-events.md)
- [contracts/http-api.md](../../contracts/http-api.md)
- [operations/backup-recovery.md](../../operations/backup-recovery.md)

## Implementation work

1. Reuse EPIC-002 jobs, receipts, resource revisions/outbox and the EPIC-005 restore path. Add provider_attempts, persisted dispatch/result identifiers, captured input read sets and provider-specific reconciliation states.
2. Use jobs.attempt_generation to fence every result even within one daemon lifetime; cancellation/reassignment changes the generation. Recheck cancellation/current authorization immediately before dispatch, and keep uncertain/orphan external attempts accounted until reconciled.
3. Implement status/cancel/resume normalization over existing events/stream epochs. Reuse saved results only when attempt, source, version and current mutation authorization still match; never assume local lease expiry stopped a remote call.

## Required deliverables

- Provider attempt ledger and reconciler on the existing coordinator.
- Dispatch/cancel/apply fencing and durable result references.
- Real/fake-provider interrupted and orphan-attempt cases.

## Observable completion and tests

- [ ] T-006-01-01: X12: same-daemon cancel/reassignment makes an earlier result ineligible to apply; cancel before dispatch prevents the affected call.
- [ ] T-006-01-02: X06/X13: restoring an older snapshot keeps uncertain external outcomes blocked/reconciling and cannot replay them through a new request identity.
- [ ] T-006-01-03: Response/event replay uses existing receipt rules without duplicate mutation or unauthorized protected delivery; client exit does not cancel accepted work.

Supplemental ownership: X06, X12, X13 in [contract cases](../../testing/contract-cases.md). Initial proof is required at the owning feature; listed later tasks repeat the applicable regression.

## Excluded work
