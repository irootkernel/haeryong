# TASK-003-05: Implement the thin Wails desktop companion

## Outcome

Attach desktop UI to the existing authenticated daemon without taking ownership of its data or lifetime.

## Inputs

- [architecture.md](../../architecture.md)
- [contracts/authentication.md](../../contracts/authentication.md)
- [ui/information-architecture.md](../../ui/information-architecture.md)

## Implementation work

1. Implement authenticated service discovery/start offer, library compatibility and endpoint validation using the one-owner per-device session model; the host retains its token and generated frames never receive it.
2. Add minimal native window/tray behavior without duplicating service state. Limit privileged Go bindings to the trusted main frame and check the sender context for exposed operations.
3. Connect the shared TASK-003-02 import/download UI to owner-selected local directory/file dialogs and a streaming destination handoff. Native operations validate the trusted sender, selected target and transfer purpose; generated pages receive neither arbitrary filesystem authority nor the host bearer. Preserve actual bytes/paths, represented empty directory entries and captured import target/base; report destination conflicts instead of silently renaming or overwriting.
4. Exercise a focused generated-frame attempt to call the native bridge or impersonate a host message with X07. Retain daemon ownership of all jobs/data and provide host recovery when generated JavaScript fails.

## Required deliverables

- desktop module and client proxy.
- packaged fixture build.
- native attach/quit tests.

## Observable completion and tests

- [ ] T-003-05-01: Quit/crash window leaves browser/library service reachable.
- [ ] T-003-05-02: Wrong library/API endpoint cannot silently attach or migrate DB.
- [ ] T-003-05-03: Native binding isolation matches passing G-VIEW evidence.
- [ ] T-003-05-04: X18 native contribution streams the owner-selected import/export through the shared UI without an all-assets envelope; represented empty directories and file bytes survive, and captured target/base remains the shared form's selection. Cancellation, destination conflict and inaccessible paths remain explicit. A generated frame cannot invoke the chooser or obtain native filesystem/management authority.

Supplemental ownership: X07, X18 in [contract cases](../../testing/contract-cases.md). Initial proof is required at the owning feature; listed later tasks repeat the applicable regression.

## Excluded work

No desktop-only implementation of domain rules or silent service auto-install.
