# TASK-003-06: Verify responsive reader and cross-client gate

## Outcome

Prove the shared reading path, accessibility behaviors and honest capability boundaries before adding wiki features.

## Inputs

- [ui/design-system.md](../../ui/design-system.md)
- [ui/flows.md](../../ui/flows.md)
- [testing/test-strategy.md](../../testing/test-strategy.md)

## Implementation work

1. Exercise Home/Library/Reader on the available primary browser/Wails host plus representative phone/tablet layout fixtures; additional physical-device combinations are recorded when available.
2. Test keyboard outline/context focus, text scaling and provider-unavailable display.
3. Compare browser/native metadata and isolate unsupported action states.
4. Reuse the G-VALUE sample packages through the actual browser/Wails import/open/interact/reopen/original-directory-download flow. Record actual picker entry fidelity and available whole-tree routes, expected versus observed answers, exact page identity and original bytes; the reader must locate a material claim, inspect its evidence and operate its meaningful control. Track concrete regressions and a bounded repair under the [knowledge-quality checkpoint rule](../../testing/knowledge-quality.md#progressive-use-checkpoints). This is the first suitable checkpoint to begin routine owner imports and subsequent reuse observations; missing owner use remains unmeasured and adds no gate.

## Required deliverables

- browser/native captures.
- keyboard/touch interaction tests.
- EPIC-003 evidence.

## Observable completion and tests

- [ ] T-003-06-01: No forced desktop-width layout on phone; verify the declared design-system viewports, text scaling, touch-target and contrast criteria and record concrete exceptions.
- [ ] T-003-06-02: Region context and app controls remain usable with keyboard/touch.
- [ ] T-003-06-03: No Wails runtime is required for browser reading and provider absence does not hide stored pages. X18 and the recorded reader task pass through real shared import/open/interaction/reopen/download; fixture-only controls cannot substitute for the delivered transport.

Supplemental ownership: X05, X18 in [contract cases](../../testing/contract-cases.md). Initial proof is required at the owning feature; listed later tasks repeat the applicable regression.
