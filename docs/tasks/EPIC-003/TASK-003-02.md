# TASK-003-02: Implement Home, Library and result transfer UI

## Outcome

Provide shared browser/Wails reading entry points and real result import/download controls on the delivered EPIC-002 transport, with independent state summaries and truthful empty states.

## Inputs

- [ui/screens.md](../../ui/screens.md)
- [ui/wireframes.md](../../ui/wireframes.md)
- [contracts/http-api.md](../../contracts/http-api.md)

## Implementation work

1. Build navigation, profile connection status, lists and basic project/lifecycle filters. One result directory is one library document even when its version contains many HTML pages; provide an entry into its page/file list without creating one document per HTML.
2. Show version/review/freshness placeholders only from actual API values.
3. Preserve filters/history and clearly disable not-yet-shipped search/AI actions. Denied/empty list checks use the existing production auth/read contract; seed labelled project/lifecycle rows where the later editing UI does not yet exist.
4. Implement the [shared import controls](../../ui/screens.md#import-export-and-file-operations): New document default or Existing document, new version with target/base captured before upload, folder/ZIP/single-HTML selection, progress, cancellation and resume. Preserve the same target/base and operation identity on response loss under the [binding rules](../../contracts/package.md#remembered-association-and-operation-base). Reader/Versions reuse this control with their exact document preselected. Record actual picker support; a FileList preserves represented file entries but cannot represent empty directories. Offer an entry-aware/native/CLI or ZIP route with directory entries when whole-tree fidelity is needed. TASK-003-05 adds native chooser/stream handoff.
5. Offer complete original-directory archive download through GET /versions/{id}/package, with authenticated streaming to a supported destination and explicit destination conflicts or unavailable transport. Do not require an all-memory Blob. This package action does not include a full backup or selected personal-record portability; show host-local CLI instructions for the latter when EPIC-005 ships.

6. Add Settings/Storage upload discovery through owner GET /uploads, detailed state/checkpoints and explicit Resume/Abandon. Losing a browser's upload ID must not hide retained staging or create a duplicate import; adopted/active/unknown pins follow the service contract.

## Required deliverables

- frontend Home/Library components with shared import, original-directory download and upload-discovery controls.
- list filters/router tests.
- S02/S03 loading, transfer, interrupted/resumable and destination-error captures.
