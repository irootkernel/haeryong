# TASK-010-06: Close integrated release gate and publish handoff evidence

## Outcome

Release only the verified scope with complete traceability, reversible installation and honest residual-risk reporting.

## Inputs

- [testing/traceability.md](../../testing/traceability.md)
- [operations/release-checklist.md](../../operations/release-checklist.md)
- [execution-protocol.md](../../execution-protocol.md)

## Implementation work

1. Check every requirement/scenario against the D-08/D-09 owner-amended applicability and the 1.4.0 delivery/evidence clarifications, actual test evidence and current artifact hashes.
2. Resolve required host/session, data-loss and explanation-quality failures for the selected baseline. Do not turn superseded security assumptions or unselected platforms into hidden release blockers.
3. Record owner/reviewer signoff, known limits and recovery instructions for the intended personal installation or distribution.

## Required deliverables

- release gate decision.
- completed acceptance/traceability records.
- release artifact manifest.

## Observable completion and tests

- [ ] T-010-06-01: Inherited scenarios under current applicability, supplemental cases and knowledge-quality gates pass for the delivered scope, with exact initial-feature and release-regression evidence.
- [ ] T-010-06-02: Every Epic completion requirement and all six narrowed readiness gates are satisfied; planned work or `fail`, `blocked` or `not_run` evidence for required current checks cannot close release.
- [ ] T-010-06-03: Artifact/toolchain/schema/contract versions match the tested installation, upgrade and local backup/restore path.

Supplemental ownership: X05 in [contract cases](../../testing/contract-cases.md). Initial proof is required at the owning feature; listed later tasks repeat the applicable regression.

No automatic public publishing or unrequested production deployment.

## Execution and handoff

Apply the shared [execution protocol](../../execution-protocol.md) and link actual evidence through the [task evidence template](../../templates/task-evidence.md). Predecessors are explicit in frontmatter; a failed or not-run required check prevents completion.
