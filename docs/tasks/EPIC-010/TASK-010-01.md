# TASK-010-01: Package reproducible service and desktop distributions

## Inputs

- [operations/deployment.md](../../operations/deployment.md)

## Implementation work

1. Pin toolchain/frontend/provider compatibility manifests and build from clean checkout.
2. Package web assets with service and separate signed native companion where identity is available.
3. Install/upgrade/uninstall without accidental data/policy removal or desktop-owned service lifetime.

## Required deliverables

- build/release pipelines.
- toolchain/SBOM/checksum metadata.
- installer/uninstaller docs.

## Observable completion and tests

- [ ] T-010-01-02: Clean install keeps default loopback/no-auto-purge policy.
