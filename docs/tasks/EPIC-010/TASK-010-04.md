# TASK-010-04: Qualify performance, Korean retrieval and resource behavior

## Outcome

Measure usability and resource behavior on declared fixtures without making unsupported scale guarantees.

## Inputs

- [requirements.md](../../requirements.md)
- [operations/observability.md](../../operations/observability.md)

## Implementation work

1. Benchmark metadata/search with documented host/corpus and exclude provider latency.
2. Evaluate Korean text/code symbol queries against expected ranked results.
3. Repeat X18/X20 with artifacts and serialized context above all former application caps. Measure streamed/chunked transfer, cursor listing, file-range delivery, first-page load without all-asset fetch, cancel/resume and client responsiveness. Separately exercise owner-configured job/provider budgets and actual disk/memory/I/O failures.

## Required deliverables

- performance/relevance report.
- Large directory, multi-page and structured-context workload metrics.
- Actual resource-failure recovery and configured job-budget captures.
