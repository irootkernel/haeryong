# TASK-002-05: Implement query API, CLI and configuration authority

## Outcome

Expose core read paths and one revisioned configuration validator used by all future clients.

## Inputs

- [Canonical import/transfer contract](../../contracts/import-workflow.md)

- [contracts/http-api.md](../../contracts/http-api.md)
- [contracts/cli.md](../../contracts/cli.md)
- [contracts/configuration.md](../../contracts/configuration.md)

## Implementation work

1. Implement capabilities, item metadata/version queries, pagination, item ETags and registry-defined JSON errors. Expose cursor file listing, small render-bootstrap descriptors and streamed/ranged exact-file delivery rather than a whole-directory render envelope. Expose authenticated operation-receipt lookup and minimal local job status/cancel endpoints from TASK-002-02. Implement owner GET /uploads discovery and each upload's status/resume/abandon contract so loss of a client upload ID does not strand retained staging.
2. Add doctor/validate/import/show/config CLI flows with stable operation IDs and original semantic preconditions. Accept plain directories/ZIPs/single HTML without author metadata; support resumable chunk transfer and path-preserving directory extraction/download. Implement authenticated event delivery/polling on stream_epoch plus sequence, including explicit resync on expired or changed epoch.
3. Validate config plan/commit and shared UI/CLI revision authority. Later scheduler/provider capabilities fail as not ready; generic local jobs and receipt/event endpoints are real.

## Grok control-plane integration

Implement the shared CLI/transport orchestration with final import ID I and separate persisted create/complete IDs U/S; preserve them, the explicit pre-transfer base and dispatch phase in the caller journal before requests. Exercise response loss at every step, recovery before a final receipt exists, same-checkpoint seal-job reuse and no inferred server workflow defaults. Expose canonical summary-only upload list rows with detail_url; checkpoint/error/ranges belong to detail. Apply purpose-by-action authority so draft.write-only staging works but direct publication remains denied. Wire cancellation to retained staging and explicit abandon to discard, without new approval prompts or artificial quotas. Reuse these helpers in the later UI rather than adding its own key/target rules.
