# TASK-001-04: Prove useful JavaScript and host separation

## Implementation work

1. Implement the html_js_v1 viewer with ordinary JavaScript/DOM, modules, framework assets, workers/WASM and browser-permitted network/CDN loading. Use a result directory containing multiple linked HTML pages and nested assets without a compulsory manifest or index.html. Demonstrate a meaningful scenario or simulation control using real scripts; no declarative-language conversion, single-file bundling or profile competition is required.
2. Run focused X07 attempts to read host DOM/storage/token, invoke a native Go binding or change Review/delete/source policy through direct calls or fabricated host messages. Keep management controls in the trusted host and bind accepted selection/context messages to the active frame/version/page. Apply the [viewer protocol](../../contracts/viewer-protocol.md) delivery-session and origin-lifecycle checks, including authored root-scope service-worker replacement and safe origin reuse, before freezing the selected loader.
3. Record early bounded X18/X19 evidence on the viewer harness: open an above-former-limit multi-page directory without fetching all assets, follow nested/root-relative links and return to the exact page/query/fragment. Keep two immutable versions open concurrently with different bytes at the same root-relative fetch, module and worker paths. Verify each request resolves within its own version after reload, new-tab navigation and the selected client lifecycle transitions. Compare selected input bytes and navigation identity. This does not prove production import durability, resumable upload, export, notes or cross-device persistence.
4. Run the required interaction, concurrent-version, delivery-session and recovery proofs on both the pinned Wails construction and actual agent-operated Aside private HTTPS construction, as well as the primary browser. Record same-site/cross-site delivery and storage behavior after reload, restart and foreground return as applicable. Exercise actual storage loss and a controlled unavailable localStorage write separately from remembered restart on the selected agent-operated Aside private browser; report actual observed transitions without claiming Android, Safari or optional Home Screen results. Exercise a broken script or stuck page and provide host close/reload/reopen where responsive, with a documented app-restart fallback if blocked. No recovery action fabricates a completed Review.
