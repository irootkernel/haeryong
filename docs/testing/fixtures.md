# Fixture corpus

**Status:** Fixture design, not generated production data or executed tests. The [worked package](../examples/package-example.md) is a byte-level contract example; it does not establish real implementation or semantic quality. Build small test repositories and focused boundary/recovery fixtures in separate test profiles during the assigned Tasks. Apply the [personal-tool amendment](../changes/2026-10-10-personal-tool-revision.md) and [directory-results amendment](../changes/2026-10-10-directory-results-revision.md); ordinary generated-page JavaScript, multi-page directories and browser networking are supported. Never copy the owner's private repositories, tokens or private browser state into committed test data.

An executable-looking or unrecognized file, undeclared asset, missing metadata, high compression ratio or a retained link pointing outside the tree is not invalid merely for that property; store its selected entry without automatically executing it or copying the link target.

Later production Tasks repeat the delivered paths without deferring this gate proof. No exhaustive networking or every-platform attack matrix is required.

Malformed host control messages include wrong types, wrong render/document/version/page IDs, stale channel identifiers and repeated messages. Alter imported local package bytes and renderer versions to exercise input/wrapper integrity (X16), preserving actual module/worker bytes. An external dependency is not falsely included in the local package's immutable-byte guarantee. A valid-looking selection event must still be incapable of starting a scan, modifying review state or granting a new source root.

## Provider and work fixtures

A fake provider must visibly identify itself and simulate: immediate success; streamed partial answer; retryable pre-dispatch failure; failure after a request may have been accepted; response saved before application; quota exhaustion; login expiry; rejected tool call; cancellation; late result after same-daemon attempt_generation change; cancellation before dispatch; cancellation with uncertain/orphan remote work; unavailable request lookup; and an unsupported usage metric.

EPIC-002 first implements local job/receipt/revision/outbox/pin fixtures without a provider. EPIC-005 uses these for backup/export and generic uncertain-operation restore. EPIC-006 adds the provider-specific ledger and real attempt reconciliation; early tasks never depend on that future runtime.

Use barriers rather than arbitrary sleeps for concurrent restore/purge, metadata rollback/user edit, policy revocation/new model call, and source deletion/result application. Exercise daemon failure at each boundary: registered job, claimed item, dispatched attempt, saved provider result, committed mutation, acknowledged response and emitted event. Inject file write/fsync/flush/rename failures separately from process termination; record the storage durability boundary (X17). Race changed semantic preconditions under the same principal/operation identity and a matching replay after its original ETag is stale (X11).

A separate real-provider fixture uses owner-approved nonsensitive source and a supported account on the chosen host. Record actual versions, authentication mode, submitted scope, exact-byte citations, observed-input or post-generation verification basis and effective provider/tool permissions, without private reasoning or credential material. Existing external agents retain normal owner tools/configuration. Managed reads reuse remembered project/provider permission and distinguish a new scope choice from each ordinary read. Passing the fake provider corpus never passes G-AI or C04 by itself. Record the actual managed invocation's auth/billing mode and verify run-local precedence handling leaves the owner's global environment, CLI configuration and shared sign-in unchanged. A supplied snapshot directory without an observed read cannot produce observed_input for every file.

## Multi-device and remote fixtures

Run two independent clients against one service/library ID. Keep a stale ETag in one while the other edits a note, review record or policy. Simulate response loss, phone suspension, revocation during event delivery, an unavailable daemon, an occupied configurable application port (default 9270) and an unrelated listener. Both clients use per-device bearer sessions remembered in their host-origin localStorage; verify normal reload/reopen without repeat pairing, explicit expiry/memory-only behavior and actual browser storage-loss recovery separately. If a content-delivery credential is selected, test exact read scope, redaction, Range/retry/resume and delivery closure/revocation independently of the management bearer. A chosen private HTTPS proxy uses the same listener. Tokenless requests and unsafe returns fail. Change stream_epoch or expire a cursor and require full server-state resync.

Restoration fixtures include a backup older than an uncertain external operation and older than a device-session revocation. The restored instance must invalidate sessions, pause network exposure and automatic/destructive work, and require reconciliation instead of blindly retrying the old request. Include restored remembered source/provider choices and automatic policy, not only device tokens. The owner reviews affected exposure, external and destructive behavior through normal settings/confirmation before resuming it. Exercise coherent portability export with exact anchored records separately from operator backup.

Local backup fixtures copy a coherent DB/object inventory and validate checksums; interrupted and mismatched copies cannot verify as complete. No backup yet and a failed latest attempt with an older complete set have different status. Checksum verification and actual trial restore are separately recorded, with unrun restore shown as not_run; manual scheduling is not an operational failure. Test complete path-preserving directory export plus selected version/page-anchored metadata separately. Ordinary source or binary files already inside the imported directory remain included; separately retained source snapshots are opt-in. Add encryption round-trip or wrong/missing-key fixtures only when that optional export format is implemented.
