## Decisions carried into the contract freeze

The selected TASK-001-06 freeze preserves the distinctions actually exercised here:

| Observed requirement | Contract consequence |
| --- | --- |
| Ordinary linked pages and nested assets work without author integration code | Keep automatic loader integration optional to authors; do not make a sidecar, index or source enrichment an import prerequisite. |
| Native bookkeeping and the Go fixture serialize inventory differently | Name each encoding and digest explicitly. Prove the identical file map; never substitute one digest for another or rewrite an authored prior pin. The production canonical inventory remains owned by the package contract. |
| Raw captures, formatted presentations and complete request payloads have different bytes | Bind each actual representation to its own digest and producing attempt; a raw-byte count is not a request-size measurement. |
| Exact citations can resolve while a required control is absent | Keep structural integrity, semantic claim support and reader-task success separate. A correct quote does not pass a missing interaction. |
| A prior explanation supplies a useful reconciliation analogy | Preserve exact inventory/version/page/region and its explanation-only scope. Do not infer caller relationships, source proof or freshness propagation. |
| A displayed source or selected scenario has a current page binding | Keep source resolution and captured display context tied to that binding; stale responses and unknown IDs cannot restore old evidence or expand authority. |
| Source-change evaluation has explicit unavailable and partial inputs | Preserve historical truth and completed/excluded/unresolved scope. Neither a hash change nor unchanged cited lines establishes a whole-project semantic verdict. |

These decisions constrain the evidence-backed freeze; they do not freeze fixture
HTTP paths or operator-only IDs into the production API. Durable context adoption,
saved answers, personal Review, import receipts and production reference
resolution remain provisional until their named implementing owners execute them.
